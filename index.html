How to read this: the heatmap is a dimensionless geometry diagnostic using only photo positions whose nadir rectangular footprints contain each terrain sample. It is not predicted RMSE. Amber stars are a distributed GCP network improved through multiple starts and point exchanges, or the legacy comparison when selected. Network coverage is the maximum distance from a terrain candidate to a selected GCP, not a measurement error. Placement exclusions need manual review. DTM-derived coordinates are planning suggestions, not surveyed control. One-centimeter accuracy requires independent surveyed checkpoints; occlusion, obstacles and reconstruction covariance remain unmodeled.
